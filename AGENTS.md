# Surface agent rules

Read [the phone field policy](docs/PHONE.md) before changing phone data, schemas, imports, or phone interfaces. It is the shared contract: one ordered list, first entry primary, no phone-type labels or separate primary flags. Preserve every number and extension.

Workspace agent instructions are generated by `cli/src/skills.ts`; update that generator rather than hand-editing generated workspace files. Keep its phone guidance aligned with the policy.
